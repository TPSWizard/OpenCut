  - type: new
    text: "Editor API v1: a typed, JSON-only surface over projects, media, timeline, playback, selection, history and export, available as `window.opencut` and over a message bridge for workers and iframes."
  - type: new
    text: "Plugins: install a manifest URL from Settings → Plugins. Panels run in sandboxed iframes as extra tabs, background modules run in Workers, both through the Editor API. A sample plugin ships with the app."
  - type: new
    text: "Scripting tab: write JavaScript against `opencut` in a CodeMirror editor, run it in a sandbox and read the console output, with ready-made examples."
  - type: new
    text: "Headless mode (`apps/headless`): render job files or scripts from the command line in headless Chromium, in batches, into MP4 or WebM."
  - type: new
    text: "MCP server (`apps/mcp`): AI agents can list and open projects, import media, lay out and edit the timeline, run scripts and render."
  - type: new
    text: "Rust core in `crates/`: time, compositor, effects, masks, gpu and bridge crates plus the `opencut-wasm` package, built from this repository with identical exports to the published package. The desktop timeline panel renders a ruler from the `time` crate."
  - type: technical
    text: "Client-only routes now use React.lazy with Suspense; the API bridge is installed once at the app root so it is available on the projects page."
