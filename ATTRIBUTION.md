assets that did not originate in this repository came from.

## Editor source (`apps/web/src`)

The editor, project storage, rendering, export, timeline, masks, animation,
captions, stickers, sounds and UI components were ported on 2026-11-02 from the
previous OpenCut codebase, [opencut-app/opencut-classic](https://github.com/opencut-app/opencut-classic)
(MIT, Copyright 2025-2026 OpenCut), commit `cf5e79e9`. Changes made during the
port:

- Next.js-specific modules (`next/image`, `next/link`, `next/navigation`) are
  replaced by `src/compat/`, built on TanStack Router.
- Server code (Better Auth, Drizzle/Postgres, Upstash rate limiting, the blog,
  marketing pages) was not carried over. The two API routes the editor uses
  live in `apps/api` instead.
- Tests moved from `bun:test` to Vitest; `src/changelog/utils.ts` reads the
  repository's `changelog/*.md` instead of content-collections.
- Bug fixes noted in `changelog/0.4.0.md`.

`apps/web/reference/` keeps the classic architecture notes (actions,
keyframes, effects renderer, country search) for the ported subsystems.

## Rust core (`crates/`)

`crates/bridge`, `crates/time`, `crates/gpu`, `crates/effects`, `crates/masks`,
`crates/compositor` and `crates/wasm` were copied on 2026-11-02 from the
classic repository's `rust/crates/*` and `rust/wasm` (MIT, Copyright 2025-2026
OpenCut), with only their `Cargo.toml` files rewritten to use the workspace
dependency table. `crates/wasm` builds the same `opencut-wasm` package that is
published on npm.

## Native editor (`crates/editor`, `crates/media`, `crates/render`, `apps/desktop`)

Written for this repository on 2026-11-02 (MIT). Notes:

- `apps/desktop/src/components/text_input.rs` is adapted from GPUI's
  `examples/input.rs` (Zed Industries, Apache-2.0): selection, IME marking and
  clipboard handling, with a commit callback and theme styling added.
- `apps/desktop/src/components/{badge,button,context_menu,label,resizable,separator}.rs`
  and `theme.rs` are upstream OpenCut's GPUI primitives (MIT).
- `crates/media` runs the FFmpeg programs (`ffmpeg`, `ffprobe`; LGPL 2.1 or
  later, or GPL depending on the build) as separate processes and ships no
  FFmpeg code. `crates/media/setup` downloads or builds the pinned version
  listed in `crates/media/setup/ffmpeg.json`, with its licence files beside it.
- Text is shaped and rasterised with `cosmic-text` (MIT/Apache-2.0) using the
  fonts installed on the system; no fonts are bundled.
- Audio output uses `cpal` (Apache-2.0).

## Shared logic (`opencut-wasm`)

[`opencut-wasm`](https://www.npmjs.com/package/opencut-wasm) 0.2.x is the
OpenCut Rust core (time, compositor, effects, masks) compiled to WebAssembly,
published from the classic repository under MIT.

## Landing page (`apps/web/public/landing`, `apps/web/src/components/landing`)

Original work, made 2026-11-12 (MIT). `editor-dark` and `editor-light` (AVIF
and WebP) are screenshots of this repository's own editor, captured from the
running app through the Editor API. The project on screen uses only media
generated for the page with FFmpeg's built-in sources (`gradients` for the
four clips, `sine` and `anoisesrc` for the two audio beds); no stock,
third-party or proprietary footage appears in them. The drawings in the

## Transitions (`crates/compositor/src/transitions.rs`, the `gl-transitions` crate)

Clip-to-clip transitions are the [gl-transitions](https://gl-transitions.com)
collection, taken as the `gl-transitions` Rust crate (version 1.0.4, catalogue
of npm `gl-transitions` as pinned in `Cargo.lock`), which embeds each
transition's GLSL source and a WGSL translation plus its uniform layout. The
collection is MIT; two transitions are BSD-2-Clause and BSD-3-Clause, with
their notices in the crate's `generated/LICENSES.md`. Each transition's author
and licence are shown by `transition_catalogue()` (`transitions.list` in the
Editor API). Nothing from the collection is copied into this repository: the
crate is a dependency, and only the vertex stage and the parameter plumbing in
`transitions.rs` are ours. Transitions that need an extra input image (a luma
matte or displacement map) are left out of the catalogue.

## Fonts and icons fetched at runtime (added 2026-11-05)

- **Fontsource** (`apps/web/src/fonts/fontsource.ts`, `apps/desktop/src/fonts.rs`):
  the font picker's *Open licence* tab lists families from the keyless
  Fontsource API and loads their files from jsDelivr; the desktop fetches a
  family's TTF files into `~/.opencut/fonts/<id>/` together with the
  package's `LICENSE` and a `provenance.json`. Each family's SPDX licence
  (OFL-1.1, Apache-2.0, MIT, UFL-1.0, …) is shown in the picker and recorded
  with the files. No font files are kept in this repository.
- **Iconify** (`apps/web/src/stickers/providers/icons.ts`): the *Icons*
  sticker category searches and browses icon sets through the Iconify API
  (MIT). Only sets whose SPDX licence is MIT, Apache-2.0, ISC, BSD, 0BSD,
  CC0-1.0, Unlicense or MPL-2.0 are offered, plus CC-BY sets marked as
  needing credit; every sticker keeps its set's licence, URL and author in
  its metadata. Icons are rendered from the API at use time; none are kept
  in this repository.

## Sticker packs (added 2026-11-12)

- **Emoji** (`apps/web/src/stickers/providers/emoji.ts`, desktop
  `apps/desktop/src/stickers.rs`): Twemoji (graphics CC BY 4.0, by Twitter,
  https://github.com/jdecked/twemoji; the pack shows the credit to give) and
  Noto Emoji (Apache-2.0, by Google, https://github.com/googlefonts/noto-emoji),
  drawn through the Iconify API with the emoji categories it lists. Nothing
  is kept in this repository; the desktop caches each set's category list
  under `~/.opencut/stickers/emoji-<set>.json`. OpenMoji is not offered
  (CC BY-SA).
- **Brands** (`apps/web/src/stickers/providers/logos.ts`): brand logos from
  Simple Icons (CC0-1.0, https://simpleicons.org), drawn through the Iconify
  API. `apps/web/src/stickers/providers/brands.json` (slug, title, brand
  colour, guidelines link, per-icon licence) is generated by
  `scripts/build-brand-stickers.py` from `data/simple-icons.json` of the
  simple-icons 16.35.0 npm package (fetched from jsDelivr on 2026-11-12) and
  the Iconify `simple-icons` collection; icons whose own licence is
  share-alike, copyleft, non-commercial, no-derivatives or custom are left
  out, CC-BY icons are marked as needing credit. Logos are trademarks of
  their owners: both editors show that notice with the pack.

## Bundled sound effects (`apps/web/public/sounds`, added 2026-11-11)

All three packs are released under CC0 1.0 (public domain dedication), so
no credit is required; it is given anyway. Each pack directory keeps the
licence text that came with it, and `manifest.json` lists every sound with
its pack.

- **Kenney Interface Sounds** (100 files) and **Kenney UI Audio** (50
  files) by Kenney Vleugels, https://kenney.nl/assets/interface-sounds and
  https://kenney.nl/assets/ui-audio, downloaded 2026-11-11 from kenney.nl.
  Files are the packs' own OGG files, renamed to URL-safe names
  (`kenney-interface/LICENSE.txt`, `kenney-ui/LICENSE.txt`).
- **The Essential Retro Video Game Sound Effects Collection (512 sounds)**
  by Juhani Junkala (SubspaceAudio),
  https://opengameart.org/content/512-sound-effects-8-bit-style,
  downloaded 2026-11-11 from OpenGameArt. The pack's 44.1 kHz 16-bit mono
  WAV files were converted to OGG Vorbis (quality 3) with FFmpeg to keep the
  pack at about 5 MB; the author's `INFO.txt` is kept in `retro/`.

## Native transcription (added 2026-11-11)

- **whisper.cpp** (ggml-org/whisper.cpp, MIT) is used as a separate
  program: `scripts/build-whisper-cli.sh` clones the pinned tag v1.8.3 and
  builds `whisper-cli` under `~/.opencut/tools/`; `apps/desktop/src/transcribe.rs`
  runs it and parses its JSON. No whisper.cpp source is kept in this
  repository.
- **ggml Whisper models** (ggml-tiny/base/small from
  huggingface.co/ggerganov/whisper.cpp, conversions of OpenAI Whisper, MIT)
  are fetched by the desktop into `~/.opencut/models/` when first used; the
  file size is checked on download and the SHA-256 and source URL are
  written beside each model. None are kept in this repository.

## Auto-reframe face detection (added 2026-11-12)

- **MediaPipe Tasks Vision** (`@mediapipe/tasks-vision` 0.10.21 from npm,
  Apache-2.0, Google). The JavaScript is bundled and the SIMD wasm
  (`vision_wasm_internal.js` / `.wasm`, about 9.6 MB) is emitted by Vite
  from `node_modules` into the site's assets, loaded only when a clip is
  reframed. Nothing from the package is kept in this repository.
- **BlazeFace short-range face detection model**
  (`apps/web/src/reframe/models/blaze_face_short_range.tflite`, float16,
  229,746 bytes, SHA-256
  `b4578f35940bf5a1a655214a1cce5cab13eba73c1297cd78e1a04c2380b0152f`),
  downloaded 2026-11-12 from
  https://storage.googleapis.com/mediapipe-models/face_detector/blaze_face_short_range/float16/latest/blaze_face_short_range.tflite.
  Its model card ("MediaPipe BlazeFace Model Card (Short Range)",
  storage.googleapis.com/mediapipe-assets) states it is licensed under the
  Apache License, Version 2.0. The card also reports Google's evaluation
  across perceived gender and five skin-tone groups. The model runs on the
  viewer's device; no frames leave the browser.
- The desktop editor has no face model: it frames by what stands out from
  each shot's background and by skin colour (own code).
- Test fixtures for this feature are drawn faces made with Pillow
  (`.cache/reframe-face.mp4`, not committed), not real people.
